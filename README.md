# The Ferma Coffee — демо MVP (web)

Мобильное веб-приложение, демонстрирующее концепцию дипломной работы «Создание мобильного
приложения The Ferma Coffee для поддержки локального бизнеса в сфере питания и фермерских
продуктов». Это **демо на mock-данных** (без бэкенда, реальной оплаты и авторизации),
воспроизводящее UI/UX, многоязычность и ключевые пользовательские сценарии из диплома.

**Слоган:** От фермы до твоего стола · Фермадан дастарханыңызға · From local farms to your coffee table

## Стек

- **Vite + React** (JS) — сборка и UI
- **react-router** (v7, library mode) — навигация SPA
- **Zustand** (+ persist) — состояние (корзина, избранное, заказы, тема, профиль)
- **i18next / react-i18next** — 3 языка: қазақша / русский / English (переключение без перезагрузки)
- **GSAP** (`@gsap/react`) — анимации (вход экранов, stagger, появление секций; учитывает `prefers-reduced-motion`)
- **@fontsource-variable/manrope** — шрифт Manrope (с поддержкой казахских глифов)
- Деплой: **Vercel** (статический SPA)

## Запуск локально

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # прод-сборка в dist/
npm run preview  # локальный просмотр прод-сборки
```

## Деплой на Vercel (бесплатно)

1. Запушить репозиторий на GitHub.
2. На vercel.com → **Add New → Project → Import** выбрать репозиторий.
3. Vercel сам определит Vite (Build: `vite build`, Output: `dist`). Ничего менять не нужно.
4. **Deploy.**

`vercel.json` в корне настраивает SPA-fallback (rewrite всех путей на `/index.html`), чтобы
прямые ссылки и обновление страницы (F5) не давали 404.

Альтернатива — CLI: `npm i -g vercel`, затем `vercel` (preview) и `vercel --prod`.

## 7 сценариев из диплома (как показывать)

1. **Заказ кофе с доставкой** — Главная → Кофе → карточка → «В корзину» → Корзина → оформление (доставка → адрес → картой при получении → подтвердить) → статус «Создан».
2. **Покупка фермерского продукта** — Каталог → Фермерские продукты → карточка → «Поставщик» → страница фермера.
3. **Самовывоз** — товар → Корзина → оформление → самовывоз → точка + время → подтвердить.
4. **Повтор заказа** — Главная → «Повторить заказ» → корзина заполнена → оформление.
5. **Информация о фермере** — Фермеры → карточка → 3 секции (Знакомство / История и регион / Продукты).
6. **Избранное в 1 клик** — ♥ на карточке → раздел «Избранное».
7. **Смена языка без перезагрузки** — переключатель KZ/RU/EN в шапке/настройках.

Демо-секундомер для метрик (≤60с / ≤30с) включается в **Профиль → Настройки → Секундомер демо**.

## Структура

```
src/
  app/        корневой провайдер (тема, сиды)
  router/     дерево маршрутов + лейауты (Tab/Plain) + boot/ошибки
  screens/    экраны (home, catalog, farmers, cart, checkout, order, profile, support, …)
  components/  переиспользуемые компоненты (ui, product, farmer, feedback, layout)
  store/      Zustand-сторы (cart, favorites, orders, ui, user, lang)
  i18n/       инициализация i18next + locales/{ru,kz,en}.json
  data/       mock-данные (categories, products, farmers, orders, promos, pickup) + аксессоры
  lib/        регистрация GSAP
  styles/     токены тем (light/dark), типографика, компоненты, экраны
  hooks/utils вспомогательные
```

## Заметки

- Изображения товаров/фермеров — брендовые градиент-плитки с эмодзи (без бинарных фото),
  что делает демо полностью оффлайн-устойчивым.
- Палитра приведена к WCAG 2.1 AA для текста; тёмная тема — полноценная инверсия.
- Данные и состояние хранятся в `localStorage` (префикс `ferma:`); язык — ключ `ferma-lang`.
