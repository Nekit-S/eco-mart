# The Ferma Coffee

Веб-версия приложения из дипломной работы «Создание мобильного приложения The Ferma Coffee для поддержки локального бизнеса в сфере питания и фермерских продуктов».

Это рабочий прототип (MVP) на демонстрационных данных, без серверной части. Он показывает идею из диплома: одно приложение связывает городскую кофейню, фермерских поставщиков и покупателя, а путь продукта виден человеку напрямую. Отсюда и слоган «От фермы до твоего стола».

В дипломе приложение спроектировано под мобильные платформы, а здесь та же концепция и те же сценарии собраны как мобильное веб-приложение. Так его проще открыть по ссылке и показать на защите.

## Что умеет

Пять разделов в нижнем меню: Главная, Каталог, Фермеры, Корзина, Профиль.

Каталог разделён на четыре категории (кофе, еда, выпечка, фермерские продукты). У каждого товара есть состав, вес, срок хранения и ссылка на поставщика. Раздел «Фермеры» это смысловой центр проекта: у каждого хозяйства своя страница с историей, регионом и списком товаров, поэтому видно, кто и где сделал продукт.

Заказ оформляется в четыре шага: способ получения (доставка или самовывоз), адрес либо точка самовывоза со временем, способ оплаты и подтверждение. Дальше можно следить за статусом. Прошлый заказ повторяется в один тап, есть избранное и история заказов.

Интерфейс работает на трёх языках (казахский, русский, английский) и переключается без перезагрузки страницы. Есть светлая и тёмная темы. Анимации сделаны на GSAP, аккуратно и с учётом системной настройки «уменьшить движение».

Воспроизводятся все семь пользовательских сценариев из диплома: заказ кофе с доставкой, покупка фермерского продукта с чтением карточки поставщика, самовывоз с выбором времени, повтор заказа, изучение страницы фермера, добавление в избранное и смена языка.

Авторизация и оплата сделаны заглушками, потому что задача прототипа показать концепцию и пользовательский путь, а не реальные платежи.

## Технологии

- Vite и React (JavaScript)
- react-router для навигации
- Zustand для состояния (корзина, избранное, заказы, тема, профиль) с сохранением в localStorage
- i18next для трёх языков и форматирования цены в тенге
- GSAP для анимаций
- Шрифт Manrope с поддержкой казахских букв

Серверной части нет. Товары, фермеры, заказы и промокоды хранятся в JSON-файлах в папке `src/data`.

## Запуск

```bash
npm install      # установка зависимостей
npm run dev      # дев-сервер на http://localhost:5173
npm run build    # сборка в папку dist
npm run preview  # просмотр собранной версии
```

Нужен Node.js 20 или новее.

## Структура

В папке `src`:

- `app`, `router` запуск приложения и маршруты
- `screens` экраны приложения
- `components` переиспользуемые компоненты интерфейса
- `store` состояние на Zustand
- `i18n` переводы на три языка
- `data` демонстрационные данные и функции доступа к ним
- `styles` цветовые токены тем, типографика и стили
- `lib`, `hooks`, `utils` вспомогательный код
